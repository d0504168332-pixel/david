# ניתוח והחלטות

- **הרשמה סגורה** — לפי הבקשה, רק מנהל המערכת פותח משתמשים. חשבון המנהל נוצר פעם אחת בדף `/setup`, ורק עבור האימייל שב-`SUPER_ADMIN_EMAIL`.
- **הרשאות** — RLS: כל משתמש רואה רק את נתוני העסק שלו. מנהל מערכת רואה הכל. עמודות רגישות בפרופיל (תפקיד, עסק, מנהל-על) מוגנות בטריגר.
- **אין שליחת מייל מהשרת** — כפתור "מייל" פותח את תוכנת המייל עם נוסח וקישור; בנייד אפשר לשתף את קובץ ה-PDF עצמו. שליחה אוטומטית עם קובץ מצורף דורשת ספק מייל (Resend וכד') — לא נדרש כרגע.
- **PDF בצד הלקוח** — המסמך מצולם ב-2x ומוכנס ל-A4; עברית ו-RTL נשמרים במדויק. בנוסף יש הדפסה (Save as PDF) לאיכות וקטורית.
- **אישור לקוח** — נוסף מעבר לאפיון: הלקוח מאשר בקישור, וההצעה מסומנת "אושרה" עם שם ותאריך.
- **נוסף מעבר לאפיון**: מצבי ריק, ולידציות, 404, מובייל מלא, השבתת עסק/משתמש, שכפול הצעה, ספירת הצעות ללקוח, keep-alive.
