# QuoteCraft — הצעות מחיר מעוצבות

Next.js 15 · Supabase · Tailwind 4 · RTL מלא.

## הקמה
1. צור פרויקט Supabase והרץ את `supabase/migrations/0001_init.sql` ב-SQL Editor.
2. הגדר משתני סביבה (ראו `.env.example`).
3. פרוס ל-Vercel, היכנס ל-`/setup` עם האימייל שב-`SUPER_ADMIN_EMAIL` וצור את חשבון המנהל.
